# 阿里云 ESA 边缘安全加速实战：从 SPA 到边缘动态 SEO

在静态网站生成（SSG）中，很多开发者常遇到的一个困惑是：**如果站点有成百上千篇文章、标签页、分类页，构建出来的静态 HTML 会越来越多，容易突破平台的文件数量限制**。

本文将介绍如何利用 **阿里云 ESA（边缘安全加速）** 的边缘函数（Edge Routine）与边缘存储（Edge KV），打造一套统一、优雅的边缘动态 SEO 解决方案。

## 核心挑战

1. **SPA 爬虫空白**：普通的 Vue 3 SPA 只有一个空白的 `<div id="app"></div>`，百度和谷歌爬虫很难爬取异步加载的文章内容。
2. **SSG 文件爆炸**：如果为每篇文章、每个标签（如 `/tags?name=xxx`）、每个分类生成独立 HTML，不仅打包缓慢，还会产生数百上千个物理文件。
3. **动态能力缺失**：静态博客无法直接记录文章的浏览量自增。

## 解决方案：ESA 边缘统一网关

### 1. 静态构建仅保留 1 个 index.html
前端构建产物依然是标准的单页应用包，文章元数据与正文编译为轻量静态 JSON。

### 2. 边缘函数动态拦截与注水
当客户端或爬虫发起请求时，ESA 边缘节点就近拦截：
- **普通用户**：直接分发 SPA，前端平滑挂载。
- **爬虫请求**：根据当前请求路径（`/article_detail/:id`、`/special/:id`、`/tags`），从同节点静态数据中提取标题、描述和正文，动态插入 HTML 模板。
- **边缘缓存**：注入后的 HTML 写入 ESA Edge Cache（`s-maxage=86400`），第二次请求直接毫秒级命中缓存。

### 3. 阅读量统计走 Edge KV
调用 `POST /api/views/:id`，边缘函数利用 Edge KV 自增并返回最新计数值，无需任何独立数据库。
