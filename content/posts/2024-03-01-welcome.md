# 欢迎访问全新架构的个人博客

这是使用 **Git + Markdown + 阿里云 ESA 边缘计算** 重构后的第一篇文章。

## 为什么进行重构？

在此之前，博客后端运行在自建的 **Strapi (Node.js + MySQL)** 之上。虽然后台灵活，但也带来了几个非常显著的痛点：
1. **服务器常驻成本高**：需要 24 小时开着云服务器，每月固定账单支出。
2. **内存消耗大、运维繁琐**：Strapi 后台在更新或构建时偶尔会由于内存不足 (OOM) 导致服务中断。
3. **写作体验割裂**：需要登录 Web 后台录入排版，不如本地配合 VS Code / Typora / Obsidian 写作顺畅。
4. **SEO 对搜索引擎爬虫不友好**：原有 SPA 页面在蜘蛛爬取时缺乏直接呈现的 HTML 语义内容。

## 新架构亮点

- **0 常驻服务器**：纯静态产物托管于阿里云 ESA Pages，全球边缘就近分发。
- **Git 驱动与免后台编辑**：文章即 Markdown 文件，管理员在文章详情页可直接点击「编辑文章」跳转 GitHub 网页端即时修改。
- **边缘动态能力**：阅读量计数由 ESA 边缘函数 + 边缘存储 (Edge KV) 实现；用户支持 GitHub 和 Gitee 快捷登录。
- **全站毫秒级搜索**：客户端轻量索引，支持全局快捷键 `Cmd/Ctrl + K` 呼出。

希望你喜欢这次重构后的阅读体验！
